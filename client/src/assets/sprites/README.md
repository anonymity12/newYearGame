# Asset Generator Output Directory

This folder contains AI-generated game sprites.

Run `npm run generate-assets` from the project root to generate sprites using Gemini AI.

## Directory Structure

After generation:

```
sprites/
├── tiles/          # Wall, floor, core tiles
├── obstacles/      # Destructible obstacles
├── players/        # Zodiac animal characters
├── enemies/        # Nian beasts
├── towers/         # Defensive towers
├── resources/      # Collectible items
├── effects/        # Visual effects
└── ui/             # UI elements
```
